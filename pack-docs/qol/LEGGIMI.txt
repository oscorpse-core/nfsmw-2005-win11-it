NFS Most Wanted 2005 — Win11 IT (pack QoL)
=========================================

Stesso pack completo IT Win11 della linea vanilla, PIU soft carriera:
economia, visual shop, marker/Junkman, vendita 100%, garage 25, DualSense tarato.
Gare / cops / storia / fasce performance = come vanilla (non alleggeriti).

INSTALL RAPIDO
--------------
1. Installa TUTTI i file in _CommonRedist\ (prima di avviare il gioco).
2. Avvia speed.exe
3. Lingua: Italian
4. Opzioni → Video: 1920x1080
5. Consigliata una CARRIERA NUOVA (non riusare save della cartella vanilla).

PAD
---
Xbox / XInput: ok.
DualSense (PS5): ok senza DS4Windows; in questo pack l'ini Widescreen
e' gia' tarata (deadzone stick, ImproveGamepad off).

Problemi tipici: SmartScreen → Ulteriori informazioni → Esegui comunque.
Se non parte: (ri)installa _CommonRedist.
