# PROMOTION — discovery → verified playbook

```text
hypothesis
  → backup (-qol binaries and/or VNDRY)
  → change only on -qol
  → smoke in-game
  → if OK:
       update qol-plan/knowledge (IT) if product-facing
       add/update agent/playbooks Evidence (EN)
       refresh KNOWLEDGE-INDEX if new file
  → if FAIL:
       playbook 09 rollback
       do NOT promote
```

**Rule:** no new playbook without a line:

`Evidence (verified YYYY-MM-DD): …`

Experimental notes may live as a short WIP section in an existing playbook marked **UNVERIFIED** until smoke passes.
